Supabase auth scaffolding CLI

PlugNPlay

One command connects a fresh project to Supabase, writes the environment file, and generates auth boilerplate for Next.js, Vite React, or Express.

View npm package View source 
$ npx plugnplay-cli init

Non-destructive

Existing files are skipped and reported, so setup can be rerun safely.

Framework-aware

Detects common project stacks and writes matching Supabase clients.

Token-safe

Personal access tokens are used only during the session and never saved.
